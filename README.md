Опубликованный портфолио-кейс Степанова Д.А.: адаптивный сайт частной практики с понятным предложением, направлениями работы, процессом консультации, стоимостью, FAQ и заявкой на адаптацию.

Анна Миронова, её опыт, стоимость и отзывы — вымышленные примеры. Проект не представляет действующего психолога. Демонстрационные отзывы подписаны непосредственно на странице. Перед запуском для специалиста нужно заменить все примеры подтверждёнными материалами и согласовать обработку данных.

## Что работает

Адаптивные разделы, якорная навигация, FAQ без JavaScript, клавиатурный фокус, переход к содержанию, учёт ограничения анимации, SEO и Open Graph, canonical на публичную демонстрацию, robots.txt и sitemap.xml, защитные HTTP-заголовки. Вместо вымышленного телефона и неработающей записи есть реальная заявка на разработку сайта через портал.

Публичная демонстрация на st8dom.ru использует его нативную форму: CSRF, серверную валидацию, согласие с ссылками на документы, защиту от спама и повторов, сохранение в базе и панель администратора. Email и Telegram зависят от настроек портала; сохранение обращения от уведомлений не зависит. Медицинские сведения не запрашиваются.

Отдельная версия Sites сохраняет существующее ограничение доступа владельцем. Общедоступная демонстрация находится на портале.

## Стек и запуск

Next.js 16, React 19, TypeScript, Vinext и Cloudflare Workers. Node.js >=22.13; CI использует Node.js 24 и Ubuntu.

```bash
npm ci
npm run dev
```

Адрес локального сервера выводится в терминале Vite. Проверки и production-сборка:

```bash
npm run verify
```

Команда генерирует типы из закреплённой версии Wrangler, проверяет TypeScript, собирает Worker и проверяет серверный HTML и SEO-артефакты. Linux или WSL требуются для Bash-скриптов и GNU timeout. Генератор типов не создаёт облачные базы данных.

## Публикация на портал

После сборки экспортируйте статический интерфейс в checkout st8dom-site:

```bash
node scripts/export-portal-demo.mjs /absolute/path/to/st8dom-site
```

Экспорт удаляет скрипты гидратации, переносит стили и изображения и вставляет защищённую форму Flask. Маршрут `/demos/psychologist/`, кейс и карточка каталога определены в репозитории портала. При изменении интерфейса повторите экспорт, проверьте портал и опубликуйте оба репозитория.

Заменить имя, портрет, образование, опыт, цену и контактные данные; убрать вымышленные отзывы; согласовать документы и подключить запись к рабочему процессу специалиста. Аналитика и рекламные счётчики не подключены. На текущем этапе production относится к опубликованному портфолио-кейсу и приёму заявок на адаптацию.
