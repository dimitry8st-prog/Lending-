# Лендинг частного психолога

![Обложка проекта](public/images/psychologist-landing-cover.png)

Современный адаптивный лендинг для частной психологической практики. Проект построен вокруг доверия, понятного пути к записи и спокойной визуальной коммуникации без агрессивных продаж.

## Демо

**[Открыть опубликованный сайт](https://psychologist-landing.ketwolsheb.chatgpt.site)**

В демонстрационной версии используются вымышленные данные психолога Анны Мироновой.

## Что реализовано

- конверсионный первый экран с чётким оффером и CTA;
- блоки «Обо мне», запросы, процесс консультации, отзывы, FAQ и контакты;
- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- семантическая структура, доступная навигация и SEO-метаданные;
- Open Graph-обложка для красивого отображения ссылки;
- спокойный минималистичный дизайн, вызывающий доверие;
- структура, готовая к подключению аналитики, форм заявок и рекламных кампаний.

## Технологии

`Next.js 16` · `React 19` · `TypeScript` · `Vinext` · `Cloudflare`

## Локальный запуск

```bash
npm ci
npm run dev
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Подготовка к рабочему запуску

Перед использованием для реальной практики необходимо заменить демонстрационные сведения, подключить обработчик формы, политику конфиденциальности, Google Analytics 4 и Google Tag Manager.
